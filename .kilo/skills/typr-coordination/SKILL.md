# Координация Typr

Только основная сессия загружает сначала глобальный `subagent-coordination`
(`~/.config/kilo/skills/subagent-coordination/SKILL.md`), затем этот навык.
Субагенты оба навыка не загружают. Общий процесс, роли, контракт scope, один
писатель, read-only review, приёмка и ретраи определены глобальным навыком.

## Проектные Границы

- Delegation-first строже общего правила: основная сессия сама делает только
  тривиальное по `AGENTS.md`, остальное делегирует.
- Основная сессия утверждает архитектуру, thread/clipboard semantics и системные
  разрешения. Высокий риск для `general-deep`: конкурентность, границы Qt/audio/input
  потоков, восстановление и машины состояний; обычная работа — `mechanic`, сложная — `general`.
- В поручении запрещай commit, revert, массовое форматирование, чтение реальных
  пользовательских секретов и изменение несвязанных файлов.
- `app.py`, `config.py`, `pyproject.toml`, установочные скрипты и канонические
  документы имеют одного исполнителя на этап. Не параллель задачи с общими
  архитектурными решениями или runtime-ресурсами.
- Проверки микрофона, `/dev/input`, `/dev/uinput`, clipboard и одной GUI-сессии
  выполняй последовательно, без конкурирующего использования устройств.

## Приёмка И Остановка

- Порядок независимого review и исправлений — в `code-review`; связанные tests/docs
  сверяй по `docs/DOCUMENTATION_POLICY.md`, проверки — по `docs/DEVELOPMENT.md`.
  Финальная приёмка остаётся за основной сессией.
- Субагент возвращает blocker при необходимости несогласованного изменения
  архитектуры/семантики, выхода за scope, использования реальных config/history,
  привилегированной или разрушительной операции, конфликта desktop-ресурса либо
  неразрешимого противоречия кода и контракта. Реализация уже согласованного
  архитектурного решения сама по себе не blocker.
- После безуспешной корректирующей итерации по глобальному процессу переоцени scope,
  уменьши задачу, смени роль или утверди решение; нетривиальную реализацию снова
  делегируй по `AGENTS.md`, а не забирай себе.
